# side-project

This repo is for side-projects.

This repository now includes a personal website page at `index.html`.

## Deploy to GitHub Pages

This repository includes a workflow at `.github/workflows/deploy-pages.yml` that deploys the site to GitHub Pages when code is pushed to `main`.

### One-time setup

1. Open **Settings** → **Pages** in this repository.
2. Under **Build and deployment**, set **Source** to **GitHub Actions**.
3. Push changes to `main` (or run the workflow manually from the **Actions** tab).

After deployment finishes, your site will be available at:

- `https://zhugexubin.github.io/side-project/`
